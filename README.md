# School Attendance System - PHP

## How to Install
1. Extract the ZIP file in your server directory (e.g., `htdocs` for XAMPP).
2. Open phpMyAdmin and create a database named `school_attendance`.
3. Import the `schema.sql` file into this database.
4. Open the project in your browser (e.g. `http://localhost/school_attendance/`)
5. Login Details:
   - **Username:** admin
   - **Password:** admin123

## Features Included
- Beautiful Modern UI Gradient Login Page.
- Simple & intuitive Dashboard.
- Mark Attendance Form with options for Present, Absent, and Leave.
- Real-time Date-based Filter to view daily attendance records.
- Database Schema and initial mock data (including user 'Fahim').
